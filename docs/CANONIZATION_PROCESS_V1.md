# Canonization Process v1.0.0

## Governing sequence

> wide extraction → candidate atoms → independent classification → dependency and contradiction analysis → evidence and formal review → explicit human admission only

1. **Source preservation:** retain coordinates, excerpts, SHA-256 hashes, and preserved Nerve sources.
2. **Atomic extraction:** use a wide aperture; immutable blind discovery receives source content only and produces candidates, never verdicts.
3. **Classification and epistemic standing:** classify each atom independently and record uncertainty, assumptions, and defeaters.
4. **Evidence/provenance:** type evidence, retain its source chain, and distinguish proposals from human findings.
5. **Dependencies:** type prerequisite, support, objection, contradiction and supersession edges. Missing targets block a complete transfer.
6. **Crossover contracts:** bridges declare source/target domains and preserved/lost structure; proof propagation is false unless separately established.
7. **Contradiction adjudication:** deterministic or semantic scans only nominate candidates. Human review assigns a governed final taxonomy status.
8. **Human admission:** admission is a separate authorized event and receipt. Import, location, verification, classification, or database presence cannot admit.
9. **Revocation/supersession:** append events and typed links; do not erase the prior record or provenance.
10. **Portability/recovery:** export versioned hash-verified packages, retain structured browser backups, validate before import, refuse conflicts, and regenerate projections from JSON.

Blind-discovery fields are immutable. Unknown fields survive all merges and transfers. Conflicts require explicit resolution and a new version; silent last-write-wins is forbidden.
